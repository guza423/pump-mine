# V13.1 · Dengeli pixel dozu, belirgin setler, set iniş animasyonu, dinlenme çubuğu

V13'ün üstüne küçük bir tur. Kullanıcı tuvalde dört şeyi onayladı:
- "dengeli doz kalsın"
- "setler kısmı belirgin olsun ve set eklenince buraya eklediği belli olsun animasyonla"
- "set 3 bitti yazsın … buton rengi son tekrar hızı ile aynı renk olsun"
- "sayaç varken set bitti olmasın … sayaça basınca sayaç ekranına dönüp istersek ordan iptal ederiz dinlenmeyi"

Okunmayan, bulanık pixel yazılar da düzelecek.

Tasarım kaynağı güncellendi: `reference/v13-pixel/Main.dc.html` (tuvalin varsayılan dozu "Dengeli"). Çelişkide bu dosya geçerlidir.

**Kapsam:** yalnızca V13'ün plansız pixel ekranları (`.px` altı). Davranış, veri modeli ve diğer ekranlar değişmez. V13'teki "Bozma" kuralları aynen geçerli.

---

## 1) Dengeli doz: fontlar

Bulanıklığın iki nedeni var:
1. Pixelify Sans keyfi boyutlarda yumuşak çiziliyor.
2. Press Start 2P 8 px ızgaralı bir font; yalnızca **8'in katı** boyutlarda keskin. 38 ya da 22 px gibi ara boyutlarda pikseller kayıyor.

Kurallar:

| Ne | Font | Boyut |
|---|---|---|
| Büyük sayılar: kilo, tekrar, dinlenme sayacı, set penceresindeki `kilo × tekrar`, yorgunluk skoru, dinlenme çubuğu süresi | Press Start 2P | **yalnızca 8'in katı**: kilo 40, tekrar 24, büyük sayaç 64, dinlenme çubuğu 32, set penceresi 24, yorgunluk 40 |
| Büyük düğmeler (`.go`, `.bb`, `.addrow`): `SET n BİTTİ`, `İDMANI BAŞLAT/BİTİR`, `GİZLE`, `GEÇ`, `-15 SN`, `N HAREKET EKLE`, `HAREKET EKLE`, `KAPAT`, `TAMAM`, `GERİ DÖN` | Press Start 2P | 16 px, `letter-spacing: 0` |
| Başlıklar: hareket adı, `PLANSIZ ANTRENMAN`, `HAREKET EKLE`, `İDMAN BİTTİ` | Saira 700 (uygulamada paketli) | bugünkü boyutlar |
| Etiketler (`SETLER`, `KİLO`, `TEKRAR`, `RIR` …), küçük sayılar, açıklamalar, arama kutusu | IBM Plex Sans (uygulamada paketli), sayılar 600–700 + `tabular-nums` | bugünkü boyutlar, en az 13 px |

- Press Start kullanılan her yerde `-webkit-font-smoothing: none; text-rendering: optimizeSpeed`.
- **Pixelify Sans tamamen kalkar**: `pixel.css`'teki bütün kullanımlar, `src/main.tsx`'teki import'lar ve `package.json`'daki `@fontsource/pixelify-sans`.
- Bu tablo jeton olarak yazılır (`--px-f-big`, `--px-f-head`, `--px-f-body`) ki V14'te bütün uygulamada aynı jetonlar kullanılsın.
- Arka plan ızgarası soluklaşır: `--grid: rgba(255,255,255,.015)`.
- Özet ekranında `İDMANA DÖN` → `GERİ DÖN` (16 px'e sığması için).

## 2) Belirgin setler kutusu
- Kutu yüksekliği 130 px. Başlıkta `SETLER` altın renk, sağdaki `n set · tonaj X kg` metni `--tx` rengi ve 600 kalınlıkta.
- Izgara: 3 sütun, satır 34 px, boşluk 10/8 px, iç boşluk `6px 4px 0 0`, `overflow-x: hidden`.
- **Kutucuk:**
  - zemin `#2f2a55`, çerçeve `inset 0 0 0 2px #4a4378`;
  - `kilo×tekrar` ortada, IBM Plex Sans 700, 17 px;
  - en yeni kutucuk 3 px altın çerçeveli.
- **RPE rozeti:** kutucuğun sağ üst köşesinde (`top: -6px; right: -3px`), en az 20×18 px. Zemini o setin hız rengi, yazısı koyu `#160f0c`, 12 px.

## 3) Set iniş animasyonu
`SET n BİTTİ`'ye basınca sırasıyla:
1. **Uçan blok:** düğmenin ortasından, altın zeminli ve `kilo×tekrar` yazan bir blok ızgaranın ilk hücresine uçar. 0,6 sn, `steps(10)`, 1,6 ölçekten 1'e; hafif yay çizer (%35'te yolun yarısı).
   - Başlangıç ve bitiş noktası **çalışma anında** `#log-set` ile ilk kutucuğun `getBoundingClientRect()` değerlerinden hesaplanır. Sabit piksel kullanma; her ekran boyunda doğru yere insin.
2. **İniş:** yeni kutucuk 0,8 sn'lik iniş animasyonu oynar: %58'e kadar görünmez, sonra altın zeminle 1,22 ölçeğe çıkar ve yerine oturur. Aynı anda kutunun çerçevesi bir kez altın yanar (0,9 sn).
3. **Ses:** mevcut arpejin üstüne 0,42 sn'de 196 Hz, 0,48 sn'de 392 Hz. **Titreşim:** `[12, 40, 24, 300, 30]`.
4. **Liste:** kendi içinde en üste kayar.
5. **Büyük dinlenme ekranı 900 ms sonra açılır.** O sırada hâlâ set ekranındaysan ve dinlenme sürüyorsa açılır. Dinlenme sayacı kayıt anında başlar; gecikme yalnızca görünüm içindir.

`prefers-reduced-motion` açıksa uçan blok ve iniş animasyonu oynamaz, dinlenme ekranı hemen açılır.

## 4) `SET n BİTTİ` düğmesi
- Metin `SET n · KAYDET` yerine **`SET n BİTTİ`**. Dinlenme ekranının üst kartı da `SET n BİTTİ` (ROM %100 değilse ` · %80 ROM`).
- **Renk, seçili son tekrar hızının rengi.** Alttaki koyu gölge de o renge göre değişir:

| Hız | Zemin | Alt gölge |
|---|---|---|
| Aynı | `#52e07c` | `#23854a` |
| Hafif | `#c6e04a` | `#6f8219` |
| Belirgin | `#ffc53d` | `#a3741a` |
| Çok | `#ff8a3a` | `#a34d1a` |
| Zar zor | `#ff3b4e` | `#9c1626` |

  Yazı her renkte koyu (`#160f0c`).
- Pliometrik ve beceri hareketlerinde hız yok; düğme bugünkü ateş rengi kalır.

## 5) Dinlenme sürerken düğme yerine dinlenme çubuğu
- Set ekranında dinlenme sürüyor ve büyük sayaç gizliyse `SET n BİTTİ` düğmesi **görünmez**. Yerinde tam genişlikte bir **dinlenme çubuğu** (`.px-restbar`) durur. İçinde:
  - solda üstte `DİNLENİYOR` (altın etiket), altında `dokun: sayacı aç`;
  - sağda süre (Press Start 32);
  - altta süreyle eriyen 6 px altın bar.

  Altın pixel çerçeveli, 64 px yüksek, `aria-label="Dinlenme sürüyor: sayacı aç"`.
- Çubuğa dokununca büyük dinlenme ekranı açılır. Dinlenme oradaki **GEÇ** ile iptal edilir, sonra düğme geri gelir. Süre dolunca da düğme kendiliğinden döner.
- Set ekranındaki 100 px'lik küçük sayaç çipi kalkar. Hareket listesi ekranındaki çip + `İDMANI BİTİR` düzeni aynı kalır.
- Dinlenme sürerken kilo, tekrar, hız ve ROM ayarlanabilir; yalnızca kayıt kapalıdır.

## 6) Testler ve layout
- `scripts/layout-check.mjs`:
  - `session` kontrolünde dinlenme sürüyorsa `#log-set` yerine `.px .px-restbar` aranır; kaydırmadan görünmeli.
  - "Uzun set listesi" döngüsünde `GİZLE` + `#log-set` yerine `GEÇ` + `#log-set` kullanılır. Son turda `GİZLE` ile çubuk ekranı da çekilir.
  - Yeni ekran görüntüsü: set eklendikten 1 sn sonra (animasyon bitmiş, dinlenme açılmış).
- Testler:
  - dinlenme sürerken `#log-set` yok, `.px-restbar` var; ona dokununca `#rest-big` açılır; `GEÇ`'ten sonra `#log-set` döner;
  - düğme sınıfı hız seviyesine göre değişir;
  - düğme metni `SET 2 BİTTİ`;
  - `pixel-classes.test.mjs` geçmeye devam eder. Yeni sınıflar `px-` önekli olsun: `px-restbar`, `px-fly`, `px-land`, `px-badge` …
